# Brand — GhostAgent

_Status: active (documents the existing design system in `src/styles.css`)_

## Palette

| Token | Light | Dark | Use |
|---|---|---|---|
| `--bg` | `#ECE9E1` paper | `#111110` | page background |
| `--ink` | `#111110` | `#ECE9E1` | text, rules, primary buttons |
| `--mu` | `#5E5B54` | `#A9A59B` | secondary text |
| `--rule` | `#111110` | `#4A4843` | 1px borders |
| `--pbg` / `--pfg` | `#111110` / `#ECE9E1` | `#262420` / `#ECE9E1` | dark panels (console, private data) |
| `--seg` | `#BDB9AE` | `#3A3935` | empty segments |
| `--accent` | `#FF4B1F` safety orange | same | primary action, danger, killswitch |
| ok / warn | `#10B981` / `#FFB020` | same | accepted / attack |

Square corners everywhere, 1px rules, no shadows except modals.

## Typography

- Display: Instrument Serif (headlines, big numbers)
- UI: Inter Tight
- Data, labels, hashes: IBM Plex Mono, uppercase labels with 0.06em tracking

## Voice

Plain, specific, short. Every claim is something a transaction can show. No "seamless", "zero exposure", or "revolutionary".
Mascot: the ghost, with Japanese sound-effect lettering (ドロン！, ガチャ！) as accents only.
